## Overall Impression
뼈대는 맞다. 학습 루프 단순, 오답 유도지 정확, 정답 카드 정보 계층 좋음. 문제는 "미니멀"이 "전부 같은 무게"로 구현됐다는 것. 카드·칩·검색창·선택지·구분선·진행바 트랙이 한 토큰(dividerColor 근검정)을 공유해 화면이 선 격자로 읽히고, iOS 위에서 Material 2 탭바·Material 다이얼로그·풀블리드 검정 Divider가 "웹/안드로이드 포팅" 인상을 준다. 가장 큰 기회: 테두리 대신 여백·톤으로 위계 만들고, 제품의 심장(오답 태그)을 홈에 올리기.

## What's Working
1. 오답 유도지가 음운론적으로 정확 — せき/ぜき/せいき/せっき. 오답이 진단 정보가 됨.
2. 클립보드 칩: hasStrings만 확인, 탭 후 즉시 제거, 작고 좌측 정렬 — 제안이지 명령 아님.
3. 정답 카드 4계층(읽기→뜻→예문→읽기→번역). 단 정답자는 1초만 봄.

## Priority Issues
1. **[P1] 한 토큰이 모든 선을 그린다.** dividerColor(#2C2C2C/#FAE100)가 Divider 5곳·Border 8곳·진행바 트랙·비활성 카드에 겸용. 설정 화면 풀블리드 검정선 3개, 홈 진행바 0%=검정 막대, 다크는 형광노랑 격자. 수정: 토큰 분리(separator 헤어라인 회색 / outline 연회색 / progress track surfaceContainerHighest), Border 1.5→1 또는 제거하고 surface 톤으로 카드 구분. `/impeccable colorize` + `/impeccable layout`.
2. **[P1] 바텀시트가 셸 내비게이터 안에 뜸.** review_filter_sheet.dart:12, add_word_sheet.dart:31 `useRootNavigator` 미지정 → 탭바 안 덮이고 시트 하단 잘림. 폭 45%는 M3 기본 constraints+중앙정렬에 `Column(crossAxisAlignment: start)` 고유 폭 → 확정. 수정: `useRootNavigator: true, useSafeArea: true`, `crossAxisAlignment: stretch`. `/impeccable adapt`.
3. **[P1] 히어로 한자가 보조 텍스트 색·한국어 폰트.** bodyMedium 기본색이 #6B3A3A 마룬이라 색 미지정 텍스트(56px 한자, 뜻, 예문) 전부 갈색. NotoSansJP는 kana 탭 라벨 2곳만 사용, 한자는 Pretendard 폴백(한국식 자형). 수정: bodyMedium 색 본문색으로, 일본어 전용 텍스트 스타일 토큰(NotoSansJP + fontFamilyFallback) 신설, 타입 스케일 15단계→6단계. `/impeccable typeset`.
4. **[P1] iOS 관례 이탈.** Material 2 BottomNavigationBar(블러 없음), Material DatePicker/AlertDialog/SnackBar×8, SegmentedButton 분홍 채움, 설정이 grouped list 아님, 최상위 Large Title 없음, 퀴즈 닫기 X 우측, AppThemeMode에 system 없음(iOS 다크 사용자도 흰 화면), 스플래시 배경 라이트 고정. `/impeccable adapt`.
